# Vita Check · 动画待办清单

一款主打「完成仪式感」的纯前端 demo。无需框架、后端或构建工具。

## 本地运行

直接打开 `index.html`，或者在项目目录运行：

```bash
python -m http.server 8080 --bind 127.0.0.1
```

访问 http://127.0.0.1:8080/ 。演示入口为 http://127.0.0.1:8080/?demo=1 ，仅在列表为空时提供五条示例任务，不覆盖已有任务。示例会在首次任务操作后随列表一起保存。

## 已实现功能

- 添加任务：回车或点击添加，拒绝空内容，最多 120 字。
- 编辑任务：双击文字，回车或失焦保存，Esc 取消；保存空内容会删除任务。
- 完成与恢复：点击圆圈或文字；圆圈支持键盘空格操作。
- 全部 / 未完成 / 已完成筛选；全局进度、剩余数量及完成率。
- 单项删除与批量清除已完成，带退场动画。
- 文档中的六种完成动画，以及马克笔、云朵两种额外效果。
- 设置中即时切换与预览动画；马克笔支持主题色、预设色与自定义颜色。
- 新增入场、悬浮反馈、按钮回弹、+1 飘字与 1.5 秒窗口的 Combo 连击。
- 已完成任务归入完成区，仍可编辑、恢复和删除。
- 亮色 / 暗色 / 自定义渐变三套主题（可选渐变的起始与结束颜色，保留流动动画并保存配色），以及可选的 Web Audio 合成音效。
- 本地保存任务和偏好；校验异常数据，存储不可用时在当前页面保留内存状态。
- 移动端布局、键盘焦点及设置面板焦点管理；尊重系统减弱动效偏好。

## 完成动画

| 动画 | 效果 |
|---|---|
| 经典删除线 | 红线从左到右划过 |
| 墨水晕染 | 墨滴扩散，文字短暂融入墨迹 |
| 碎裂消散 | 文字碎片向四周飞散 |
| 闪电划过 | 电光闪过，留下完成标记 |
| 折叠收起 | 纸张折起，再归入已完成区域 |
| 粒子爆炸 | 彩色粒子向四周散开 |
| 马克笔涂划 | 半透明荧光笔，可自定义颜色 |
| 云朵庆贺 | 小云朵从任务位置升起 |

临时特效结束后恢复可读的完成态。预览与真实任务共用同一套动画实现。粒子使用 DOM + CSS，不需要外部资源。

## 文件结构

- `index.html`：页面结构，按 storage → animations → app 顺序加载脚本。
- `js/app.js`：任务状态、筛选、渲染、设置及音效。
- `js/animations.js`：动画注册、完成效果、预览与 Combo。
- `js/storage.js`：localStorage、数据校验与内存回退。
- `css/style.css`：布局、组件、响应式及键盘焦点。
- `css/themes.css`：三套主题变量。
- `css/animations.css`：动画和特效样式。

## 数据说明

使用 `vita_check_todos` 与 `vita_check_prefs` 保存数据，兼容原有任务。清空所有数据需要确认。数据仅保存在当前浏览器，不跨设备同步；清除浏览器数据会丢失任务。浏览器存储不可用或写入失败时，当前页面仍可使用，刷新后无法保证保留更改。
