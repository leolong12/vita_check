# 酷炫动画待办清单 · Vita Check ✅

> 一款主打「**完成仪式感**」的纯前端待办工具。
> 区别于传统枯燥的待办列表，每完成一条任务都能获得强烈的视觉反馈与成就感。

---

## ✨ 核心特性

- **纯静态、零后端、零构建**：浏览器打开即用
- **3 种酷炫「划掉」动画**可随时切换
- **完成庆祝动效**：+1 飘字、Combo 连击
- **3 套主题**：亮色 / 暗色 / 多彩渐变（带流动动画）
- **本地持久化**：刷新不丢失，自动保存动画与主题偏好
- **响应式**：桌面、移动端均可舒适使用
- **可访问性**：键盘友好、支持减弱动效偏好

---

## 🎬 3 种划掉动画

| 动画 | 效果 |
|------|------|
| ➖ 经典删除线 | 红线从左到右穿过文字，文字变灰 |
| 🖊️ 马克笔涂划 | 倾斜荧光笔从左到右划过（颜色可在设置中自定义） |
| ☁️ 云朵庆贺 | 数朵小云从行内升起，文字保留完成态 |

在 **设置 → 划掉动画风格** 中切换，并点击「预览当前动画」即时查看效果。

## 🚀 本地运行

### 方式一：直接打开
双击 `index.html` 即可在浏览器中使用。

### 方式二：本地静态服务器（推荐）
```bash
# 进入项目目录
cd vita_check

# 任选其一
npx serve .
# 或
python -m http.server 8080
```
然后访问终端提示的地址。

## 🛠 技术栈

| 技术 | 用途 |
|------|------|
| HTML5 | 语义化结构 |
| CSS3 | 主题变量、transition、@keyframes、clip-path、mix-blend-mode、filter |
| 原生 JavaScript (ES6+) | 交互逻辑，零框架依赖 |
| localStorage | 待办数据与偏好持久化 |

**核心原则**：能用 CSS 实现的动画绝不写 JS，保证性能流畅。

## 💡 使用提示

- **添加**：输入框输入后回车，或点「添加」
- **完成**：点击左侧圆圈或文字 → 触发划掉动画 + 庆祝反馈
- **编辑**：双击词进入编辑，回车 / 失焦保存，Esc 取消
- **删除**：悬停词点 ×
- **清除已完成**：底部一键清除
- **设置**：右上角 ⚙️ 打开，切换动画 / 主题 / 音效
- **主题快捷切换**：右上角 🎨 按钮循环切换

---

## ⚠️ 数据说明

所有数据存储在浏览器的 **localStorage** 中：
- ✅ 刷新页面不会丢失
- ❌ **清除浏览器数据** 会丢失待办列表
- ❌ 不同浏览器 / 设备之间 **不同步**（如需同步需扩展云端 API）
