# Vita Check · 词云待办

**当前版本：0.0.1** · [更新记录](./CHANGELOG.md)

把想做的事排成一张词云。任务以不同大小、颜色和方向组合，点击文字即可完成，完成后在原位淡化并保留划线。

Vita Check 是一个纯浏览器端 demo，使用 HTML、CSS 和原生 JavaScript，无框架、后端或构建依赖。

## 快速运行

直接用浏览器打开 `index.html`，或在项目根目录启动本地静态服务器：

```bash
python -m http.server 8080 --bind 127.0.0.1
```

- 日常入口：[http://127.0.0.1:8080/](http://127.0.0.1:8080/)
- 示例入口：[http://127.0.0.1:8080/?demo=1](http://127.0.0.1:8080/?demo=1)

示例入口仅在当前任务列表为空时提供 24 条示例任务，不覆盖已有任务。示例初始只在内存中，首次添加、编辑、完成或删除任务后，整份列表会一同保存。在示例入口清空任务后重新加载页面，会再次生成示例。

也可以运行 `npx serve .`，然后访问它显示的地址。

## 当前功能

- **词云布局**：根据文字实际尺寸自动避让，横排、竖排、斜排交错；长任务自动换行，任务较多时画布向下扩展。
- **重新排布**：改变任务的位置、字号、方向和颜色，生成另一种组合。排布结果不单独保存，刷新后按默认排布生成。
- **任务管理**：添加、编辑、完成、恢复、单项删除及批量清除已完成任务。
- **进度统计**：显示未完成数量、完成百分比和进度条，始终按整个任务列表计算。
- **完成反馈**：经典删除线或马克笔涂划，以及 +1 飘字、Combo 连击和可选音效。
- **个性化**：亮色、暗色、自定义渐变主题；马克笔支持主题色、预设色和自定义颜色。
- **本地保存**：自动保存任务和偏好，兼容原有数据；存储不可用时保留当前页面的内存状态。
- **使用适配**：响应式布局、键盘操作、设置面板焦点管理及系统减弱动效偏好。

词云始终展示全部任务，已完成项保留在原位，仍可编辑、恢复和删除。字号与颜色用于视觉排版，不表示任务优先级、截止日期或完成次数。

## 操作方式

| 操作 | 方式 |
|---|---|
| 添加 | 在底部输入内容，按 Enter 或点击“加入词云” |
| 完成 / 恢复 | 点击任务文字；重复操作切换状态 |
| 编辑 | 双击文字，或选中任务后按 F2，打开编辑窗口 |
| 保存编辑 | 在编辑窗口按 Enter 或点击“保存修改” |
| 取消编辑 | 点击“取消”或按 Esc |
| 删除单项 | 点击文字悬浮或获得焦点时出现的 ×，或使用编辑窗口中的“删除任务” |
| 清除已完成 | 点击底部“清除已完成”；没有已完成任务时按钮禁用 |
| 更换排布 | 点击词云右上方“重新排布” |
| 打开设置 | 点击右上角 ⚙；点击关闭按钮、遮罩或按 Esc 关闭 |
| 快捷切换主题 | 点击右上角 ◐，循环切换三种主题 |

输入内容会去除首尾空白，添加和编辑均限制最多 120 个字符。编辑窗口必须填写非空内容，并通过保存操作提交；失焦不会自动保存。删除和清除已完成直接执行；设置中的“清空所有数据”会先请求确认。

键盘操作：Tab 选择任务，空格或 Enter 完成 / 恢复，F2 编辑，Delete 删除。

## 动画与设置

| 完成动画 | 效果 |
|---|---|
| 经典删除线 | 从左向右画出划线，任务文字淡化 |
| 马克笔涂划 | 半透明荧光笔色块从左向右划过，任务文字淡化 |

在“设置 → 划掉动画风格”中切换，点击“预览当前动画”可查看效果。马克笔提供六种预设颜色、跟随主题和原生取色器。

完成单项时显示 +1；在 1.5 秒内继续完成任务会累积 Combo。全部任务完成时显示文字提示。新增和删除分别带缩放入场、淡出退场反馈。

选择“设置 → 主题配色 → 渐变”后，可分别调整起始与结束颜色，即时预览并自动保存。默认配色为 `#6366f1` 和 `#ec4899`，页面背景保留流动动画，文字配色根据两端颜色的平均亮度匹配明暗。

音效默认关闭，开启后通过 Web Audio 合成完成提示音，无需加载音频文件。系统启用减弱动效时，页面缩短过渡和动画，并停止生成 +1 / Combo 飘字。

## 项目结构

```text
vita_check/
├── index.html
├── css/
│   ├── themes.css       # 三套主题变量与渐变背景
│   ├── style.css        # 基础组件、设置与通用样式
│   ├── animations.css   # 两种划线、飘字与通用动画
│   └── cloud.css        # 词云工作台、编辑窗口与移动端样式
├── js/
│   ├── storage.js       # 本地存储、数据校验与内存回退
│   ├── animations.js    # 动画注册、样式切换、预览与 Combo
│   ├── cloud.js         # 尺寸测量、碰撞避让、重新排布与尺寸适配
│   └── app.js           # 任务状态、交互、统计、设置与音效
├── README.md
└── 酷炫动画待办清单 - 项目说明文档.md
```

脚本依次加载 `storage.js → animations.js → cloud.js → app.js`；`cloud.css` 最后加载，用于覆盖基础列表样式。

## 数据与运行边界

任务保存在 `vita_check_todos`，偏好保存在 `vita_check_prefs`。已有任务可继续使用；旧动画偏好若已不受支持，会回退到经典删除线。

数据属于当前浏览器和访问来源。不同浏览器、设备、域名或端口的存储互相独立；直接打开文件和通过本地服务器访问也可能使用不同的存储区域。清除浏览器数据或确认“清空所有数据”会删除对应任务。

存储不可用或写入失败时，当前页面仍可操作，但刷新后无法保证保留更改。读取异常 JSON 时回退默认值，异常任务条目会被过滤；这不等同于数据备份或自动修复。

当前没有云端同步、账号、导入导出、分类标签、优先级、截止日期、每日统计或 PWA 安装功能。

## 开发与验证

无需构建。修改后通过静态服务器检查页面，提交前运行：

```bash
node --check js/storage.js
node --check js/animations.js
node --check js/cloud.js
node --check js/app.js
git diff --check
```

项目没有配置自动测试框架、打包工具或覆盖率要求。已有 Chromium 检查记录覆盖任务增删改、完成与恢复、重新排布、刷新保存、两种动画及预览、设置和键盘操作；删除与重置检查在独立临时浏览器环境进行。

此前检查了桌面、320px / 390px 手机宽度，以及含 70 条任务和长文本的场景，未发现文字边界重叠或横向溢出。其他浏览器和真实手机尚未实测；这些记录不代表所有数据规模和设备都已覆盖。

详细功能、模块说明和手动验收清单见[项目说明文档](./酷炫动画待办清单%20-%20项目说明文档.md)。

| 更新级别 | 版本变化示例 | 适用范围 |
|---|---|---|
| 整体重做 | `0.x.x → 1.0.0` | 整体产品或架构重做 |
| 较大升级 | `0.0.x → 0.1.0` | 较大功能升级，末位归零 |
| 小更新 | `0.0.1 → 0.0.2` | 功能调整、问题修复及文档更新 |

每次发布同步更新 `VERSION`、README 的当前版本和 `CHANGELOG.md`，提交说明包含版本号，并创建对应 Git 标签。本次发布版本为 `0.0.1`。
